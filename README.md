# Multi-orientation COSMOS QSM and Susceptibility Tensor Imaging

MATLAB code and example in vivo data (12 head orientations, Wave-CAIPI at 3T with R = 5x3 acceleration and 1.1 mm isotropic resolution) for COSMOS QSM and susceptibility tensor imaging (STI).

## Usage

Run `script_wave_3T_R5x3_1p1mm_COSMOS_STI.m` from the repository folder in MATLAB. It loads the 12-orientation data, then computes and displays the COSMOS and STI solutions.
